# Unit I – Programs

## 1. Numerical Data Processing

A C++ program that accepts a positive integer and calculates the sum of its individual digits. The program demonstrates basic C++ programming constructs such as variables, operators, loops, and functions.

**Concepts used:**

* Variables and Data Types
* Arithmetic Operators
* Input and Output
* Functions
* While Loop
* Modulus Operator
* Integer Division

---

## 2. Prime Number Generation

A program that accepts a number and generates all prime numbers up to the given limit. The program checks whether each number is divisible by numbers within its range.

**Concepts used:**

* Variables
* Conditional Statements
* For Loop
* Nested Loops
* Functions
* Prime Number Logic
* Arithmetic Operators

---

## 3. Student Information Management

A C++ program that uses a class to store and display student information. The program demonstrates how classes and objects can be used to represent real-life entities.

**Concepts used:**

* Classes and Objects
* Data Members
* Member Functions
* Encapsulation
* Constructors
* Object Creation
* Access Specifiers

# Unit III – Programs

## 1. Abstract Class

A program demonstrating the concept of an abstract class in C++. An abstract class provides a common interface for derived classes and contains at least one pure virtual function.

**Concepts used:**

* Abstract Classes
* Pure Virtual Functions
* Inheritance
* Virtual Functions
* Function Overriding
* Runtime Polymorphism

---

## 2. Operator Overloading

A program demonstrating operator overloading in C++. Operator overloading allows operators such as `+`, `-`, `*`, and `==` to work with user-defined objects.

The concept can be applied to real-life objects such as complex numbers.

**Concepts used:**

* Operator Overloading
* Unary/Binary Operators
* Classes and Objects
* Member Functions
* Constructors
* Returning Objects
* `+` Operator
* `-` Operator
* `*` Operator
* `==` Operator

---

## 3. Constructor and Copy Constructor

A program demonstrating different types of constructors used for initializing objects.

The program explains how objects can be initialized using default constructors, parameterized constructors, and copy constructors.

**Concepts used:**

* Default Constructor
* Parameterized Constructor
* Copy Constructor
* Object Initialization
* `this` Pointer
* Constructor Overloading

On Windows:

The purpose of this repository is to **learn, implement, and demonstrate Object-Oriented Programming concepts in C++ through practical and real-life examples**.

The programs provide hands-on understanding of concepts such as:

* Classes and Objects
* Encapsulation
* Inheritance
* Abstraction
* Polymorphism
* Constructors
* Destructors
* Virtual Functions
* Operator Overloading
* Code Reusability

These concepts are implemented through different real-life scenarios to make Object-Oriented Programming easier to understand and apply.
